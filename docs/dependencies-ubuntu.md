# Ubuntu dependencies

Build tools:
- build-essential
- cmake
- ninja-build
- pkg-config

Qt:
- qt6-base-dev
- qt6-declarative-dev
- qt6-wayland-dev
- qt6-webengine-dev

Runtime integrations are optional and are detected at runtime. WINUX11 uses standard Linux components such as systemd, NetworkManager, PipeWire/WirePlumber and apt when present.
